为什么会有这个工具

你手上有个 HTML 文件——一份报告、一个看板、一个内部小工具——需要挂到 一个同事能打开的地址上。常见的两条路：要么用碰不到你数据的云平台， 要么起一个只当文件服务器的裸 nginx。html-golive 走中间：自己跑起来， 数据不出内网，同时该有的便利一样不少。

🔒

数据留在你这儿

完整跑在你自己的机器或服务器上。不用注册账号，没有埋点，默认零外呼——断网环境照样能用。

🪶

起步零依赖

核心安装只用标准库。本地文件系统加 SQLite，不用先去开数据库或对象存储。

📈

跟着你一起长大

一个 yaml 就能换成 Supabase 或任意 S3 兼容存储（MinIO / 腾讯 COS / 阿里 OSS / 火山 TOS）。命令不变，后端变大。

你会得到什么

下面这些都在安装包里——装一次，不用再去找插件。

🚀

发布与回滚

每次发布都会给上一版存快照，golive rollback 随时退回任意一版。

✏️

在浏览器里改

owner 和 maintainer 能在线上页面直接编辑——改个错别字不用回去动源文件。保存同样会扫描并存快照。

🗄️

给静态页面的数据库

页面里自动注入 window.TemplateAPI 和 window.SupabaseAPI，纯 HTML 也能读写真实数据行。

🛡️

凭证扫描

上线前用规则识别 API key、token 和个人信息，还可以选择让大模型再复核一遍。

🎨

19 套内置样式

--style 把一份没有样式的文档变得能见人。字体走公共 CDN 或你自己的镜像。

🧑‍💼

管理后台

/admin 是一个完全自包含的门户：站点总览、移交 owner、维护者、回滚、统计和审计日志。

🔑

真实的身份认证

图快用静态 token，正式环境走 OIDC——Google、Auth0、Okta、Azure AD、Keycloak、Authentik 都有一行预设。

🕸️

克隆任意页面

golive clone <url> 抓取一个公开页面，内联它的资源，再作为你自己的站点重新发布。

🐳

开箱即用的 Docker

提供 Dockerfile 和 compose 文件（含可选 MinIO profile），一条命令从零到服务跑起来。

快速开始

三步，大约一分钟。开始之前不需要写任何配置文件。

安装

需要 Python 3.9 或更高版本。可选的 extras 提供图片压缩和 S3 支持。

$ pip install html-golive

发布一个页面

指向任意 HTML 文件即可。它会扫描凭证、套用样式、内联资源并登记站点。

$ golive publish report.html --style minimal

把它跑起来

默认只监听 localhost。准备分享给别人时加上 --host 0.0.0.0，同时配好 token 或 OIDC。

$ golive serve 🚀 http://localhost:8787/ · 管理后台：/admin

架构

三层可插拔接口。从左边这列起步，撑不住了再往右换——你的命令和你的页面 都不用改。

存储

  • local 本地文件系统（默认）
  • supabase storage bucket
  • s3 MinIO / COS / OSS / TOS

注册表

  • sqlite 单文件（默认）
  • supabase Postgres 表

数据层

  • none 只做静态页面
  • postgrest Supabase / 任意 PostgREST

身份

  • none 仅本机访问
  • token 共享令牌
  • oidc Google、Okta、Keycloak…

命令速查

十三条命令覆盖整个生命周期，完整细节见用户手册。

命令作用
publish扫描、套样式、内联资源并部署一个 HTML 文件
list列出所有已登记站点，含大小和 owner
rollback回滚到之前的某个快照
serve启动 HTTP 服务和管理后台
preview本地预览一个文件，不登记站点
clone抓取一个公开页面并重新发布
maintainer给某个站点授予或撤销编辑权限
admin打开管理后台
styles列出 19 套内置视觉样式
data / db查看和管理数据后端
migrate-check找出 HTML 里跟特定环境绑死的引用
doctor诊断配置和连通性
