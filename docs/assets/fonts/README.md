# Landing page typefaces

The Latin variable-font subsets are served locally, with `font-display: swap`.
Chinese text uses the device’s available Chinese font; there are no font CDN
requests when viewing the page.

- Manrope, 400–800: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/manrope), licensed under the adjacent `manrope-OFL.txt`.
- Space Grotesk, 500–700: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/spacegrotesk), licensed under the adjacent `space-grotesk-OFL.txt`.

The WOFF2 Latin subsets were obtained from Google Fonts on 2026-10-20.
